# مجلد الأصوات (GitHub Audio Folder)
يمكنك وضع أي ملفات صوتية (صوت المعلم، نطق، تلاوة، أناشيد) بصيغة MP3 أو WAV هنا في مستودع GitHub الخاص بك.
طريقة الاستخدام في حقل "رابط الصوت" في لوحة الإدارة:
/audio/اسم_الملف.mp3
أو
/audio/اسم_الملف.wav

كما يمكنك أيضاً استخدام روابط مباشرة لملفات صوتية من:
- Google Drive
- Dropbox
- أو ترك الحقل فارغاً ليعمل محرك النطق والقراءة الآلية للمتصفح مجاناً تلقائياً.
